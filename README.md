# Website Bank Sampah Berkah Mandiri

Website statis siap untuk GitHub Pages.

## Struktur
- `index.html` — halaman utama lengkap
- `.nojekyll` — memastikan GitHub Pages tidak memproses situs dengan Jekyll
- `assets/images/logo-bsbm.png` — logo BSBM
- `assets/images/favicon.png` — favicon

## Deploy
Upload isi folder ini ke repository GitHub Pages. Pastikan `index.html` berada di folder yang menjadi sumber Pages.

URL aplikasi BSBM sudah diarahkan ke Web App Apps Script yang digunakan pada proyek sebelumnya. Jika URL aplikasi berubah, edit `href` pada tombol `Buka Aplikasi BSBM` di `index.html`.
