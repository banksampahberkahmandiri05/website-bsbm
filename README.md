# Bank Sampah Berkah Mandiri – GitHub Pages

Website publik BSBM RT 005 RW 05 Cilodong – Depok.

## Upload
Upload seluruh isi folder ini ke repository GitHub Pages.

## Aplikasi
Tombol Login Aplikasi membuka `aplikasi.html`, yang menampilkan Web App BSBM di dalam iframe. URL Apps Script tidak ditampilkan sebagai link pada halaman publik.

## Catatan
Aplikasi Apps Script harus tetap mengizinkan framing (`ALLOWALL`) agar iframe dapat dimuat.
